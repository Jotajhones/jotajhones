# Olá, sou João Pedro de Lima! 👋

### Sobre Mim

Sou João Pedro de Lima, um programador web em formação com habilidades em desenvolvimento front-end e back-end. Meu objetivo é aplicar e expandir meus conhecimentos em projetos reais para me consolidar no ecossistema web.

Tenho experiência prática na criação de APIs RESTful, como no meu [Projeto Integrador de loja online](https://github.com/Jotajhones/PI-CursoTecnico), e na construção de um [sistema web CRUD com interface e API](https://github.com/Jotajhones/API_frontEnd). Também desenvolvi um [repositório de livros usando React](https://github.com/Jotajhones/repositorio-livros-hp), com funcionalidades como busca, rankeamento e favoritos. Sou uma pessoa criativa, com foco em excelência técnica, e busco me aprofundar cada vez mais no desenvolvimento de soluções robustas e funcionais.
